Initial conditions and endpoint conditions

For y″ + 4y = 0, the condition y(0) = 0 gives y = C sin(2x). An initial slope fixes C because y′(0) = 2C. A right endpoint instead asks whether C sin(2b) can equal the target value.

If sin(2b) ≠ 0, one C works. If sin(2b) = 0, every C works for a zero target, while no C works for a nonzero target. All curves in the first exploration solve the ODE exactly.

Why are some λ values called eigenvalues?

The equation y″ + λy = 0 says −y″ = λy. The operation “take two derivatives and change the sign” sends an eigenfunction to a multiple of itself. The multiplier is its eigenvalue.

The ODE and the boundary conditions belong together. A candidate may satisfy the ODE but miss the right endpoint. A polynomial may meet both endpoints but fail the ODE. An eigenfunction must satisfy both requirements and be nonzero.

The zero function satisfies these homogeneous equations for every λ. It does not count as an eigenfunction. The amplitude control therefore stays positive. Any nonzero multiple of an eigenfunction has the same eigenvalue.

Read the three cases and the two boundary conditions

For two zero endpoint values, the candidates are multiples of sin(√λ x) when λ > 0, of x when λ = 0, and of eμx − e−μx when λ = −μ² < 0. The last two can return to zero at L > 0 only when the whole solution is zero.

For y(0) = y(L) = 0, the allowed values are λn = (nπ/L)², with eigenfunctions sin(nπx/L), n = 1, 2, ….

For y′(0) = 0 and y(L) = 0, the positive candidates are cosines. The allowed values are λn = [(2n − 1)π/(2L)]², with eigenfunctions cos[(2n − 1)πx/(2L)], n = 1, 2, …. Zero and negative λ again give no nonzero solution for these particular boundary conditions.

Doubling L divides every eigenvalue of a fixed mode by four. No matrix or determinant is needed: apply the two endpoint conditions to the general solution.

A short classroom sequence
  1. Try target A, then B and C. Change C before revealing the solution count.
  2. In the eigenvalue view, compare λ = 1, 2, and 4 on [0, π]. Scan to the next allowed value.
  3. Double the interval length. Then change the left condition from a value to a slope. Compare the allowed values.
  4. In the last view, choose an allowed mode and compare y, −y″, and λy. Try the polynomial too. Matching at one point does not establish an identity on the whole interval.

Curves and derivatives are analytic. Sampled paths are used for drawing. Positive rescaling makes the displayed maximum |y| equal to A and leaves the boundary test unchanged.
